# 模块3 Research Gap 识别 Agent · 任务规划（task_plan）

## 任务目标

基于模块 2 产出的知识库，识别材料科学文献中未被充分探索的方向、矛盾结论、缺失知识连接，输出带证据链与新颖性判定的 Gap 清单，作为路线 A 搜索的种子输入。

## 约束条件

- Gap 必须附证据链（文献交叉引用 + DOI）
- 区分「新知」与「已知」（Sciverse 回查确认）
- 标注可操作性（能否转化为路线 A 搜索种子）
- 评估三要素：准确率、新颖性、可操作性
- 遵循 `.trae/rules/04-literature-agent.md` 第 4 节 Gap 识别方法

## 阶段划分

### 阶段 1：覆盖率分析引擎
- [ ] 构建成分×结构×性能研究矩阵
- [ ] 统计研究密度，定位空白格
- [ ] 空白格过滤（排除物理/化学不可行组合）

### 阶段 2：矛盾检测
- [ ] 同体系多文献数值归一化对比
- [ ] 设定冲突阈值，标记矛盾结论
- [ ] 矛盾解释输出（LLM 辅助归因）

### 阶段 3：LLM 推理与验证
- [ ] LLM 基于知识库提出 Gap 候选（连接发现 + 假设生成）
- [ ] Sciverse 回查确认未被文献覆盖
- [ ] 新颖性评分（已知 / 部分已知 / 新知）

### 阶段 4：Gap 清单输出与评测
- [ ] 结构化 Gap 清单（描述 + 证据链 + 交叉引用 + 可操作性）
- [ ] 准确率评测（人工标注小集）
- [ ] 与模块 4 报告生成、模块 5 路线 A 联动

## 验收标准

- [ ] 输出 Gap 清单含证据链与新颖性判定
- [ ] 覆盖率分析定位 5+ 个候选空白
- [ ] 矛盾检测标记 3+ 个冲突结论
- [ ] 人工评测准确率 ≥ 0.7

## 技术决策

### 决策 1：方法组合
- **背景**：Gap 识别有覆盖率分析、矛盾检测、连接发现、LLM 推理四类方法
- **选项**：单一 LLM 生成 / 纯数据驱动 / 数据驱动 + LLM 推理验证
- **选择**：覆盖率分析 + 矛盾检测（数据驱动）+ LLM 推理验证（生成驱动）
- **理由**：数据驱动方法可靠可复现，LLM 补足生成能力，两者互补且证据链完整

### 决策 2：新颖性判定
- **选择**：Sciverse 回查 + 人工复核
- **理由**：LLM 自评不可靠，必须外部检索确认「未被覆盖」
