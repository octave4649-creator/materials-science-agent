# 模块5 路线A 构效关系搜索融合 · 任务规划（task_plan）

## 任务目标

将 LLM 与搜索算法（遗传算法 GA / MCTS / 贝叶斯优化 BO / 符号回归 SR）深度融合，构建「候选生成→评估→筛选→数据库验证」的构效关系发现闭环，输出带化学解释与证据链的新材料设计假设。

## 约束条件

- 搜索方法与 LLM 深度融合（LLM 参与生成/评估/剪枝），非仅生成搜索代码——创新性评分关键
- 产出可证伪、带证据链的构效关系假设（Gap 为种子输入）
- 两级验证协议：内层 CV 做搜索决策，held-out 集做最终评测，防污染
- 结论须可解释（显式描述符/关系式 + 化学依据）
- 依赖模块 6 数据库交叉验证接口

## 技术决策

### 决策 1：主搜索算法
- **背景**：GA/MCTS/BO/SR 各有适用场景
- **选项**：单一 GA / GA+MCTS 混合 / 四种全上
- **选择**：GA 全局探索 + 符号回归显式化为主，MCTS 处理序列决策，BO 处理连续参数
- **理由**：混合覆盖成分空间与工艺空间，SR 保证可解释性（科学意义维度）；先实现 GA+SR 最小闭环

### 决策 2：LLM 融合深度
- **选择**：三角色全参与（生成器/评估器/剪枝器）
- **理由**：赛题创新点在于深度融合；三角色均可消融，便于量化 LLM 贡献

### 决策 3：验证协议
- **选择**：内层 CV 决策 + held-out 评测（两级隔离）
- **理由**：参考 Automat 两级验证，避免搜索过程在验证集上过拟合
