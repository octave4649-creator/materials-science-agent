# 模块4 调研报告生成 Agent · 任务规划（task_plan）

## 任务目标

将模块 1-3 的产物（检索清单、知识库、Gap 清单、证据链）整合为结构化、可读、证据可溯源的文献调研报告，支持导出 Markdown/HTML，并对接初赛方案文档与复赛实验报告模板。

## 约束条件

- 报告章节结构遵循 `.trae/rules/04-literature-agent.md` 第 5 节模板
- 所有结论必须带证据引用（[n] 编号 + DOI 回链），禁止无证据断言
- 结构化程度与可读性是赛题评测维度，须量化自检
- 输出对接 `.trae/rules/10-submission-templates.md` 三阶段提交物

## 阶段划分

### 阶段 1：报告模板与 Schema
- [ ] 定义报告章节结构（摘要/背景/方法/结果/讨论/结论/参考文献/证据链附录）
- [ ] 设计报告数据 Schema（与模块 3 Gap 清单、模块 2 知识库对接）
- [ ] 参考提交模板预设初赛/复赛两版模板

### 阶段 2：内容组装
- [ ] 从知识库聚合研究现状综述
- [ ] 从 Gap 清单生成「研究发现与缺口」章节
- [ ] 证据链自动生成参考文献列表与引用编号映射

### 阶段 3：可读性优化
- [ ] 自动生成摘要（LLM 提炼核心结论）
- [ ] 表格/图表自动生成（Gap 矩阵表、研究密度热力图）
- [ ] LLM 润色章节（术语一致、层级清晰），数字一律回查证据链防幻觉
- [ ] 术语表与缩写表生成

### 阶段 4：输出与版本管理
- [ ] Markdown / HTML 双格式导出
- [ ] 报告版本记录（每次生成时间戳 + 数据快照 hash）
- [ ] 与初赛方案文档（≤4 页）对接裁剪

## 验收标准

- [ ] 全链路一键生成调研报告
- [ ] 报告每个结论可回溯到证据链条目
- [ ] 结构化程度自检清单通过（章节完整、层级规范、引用齐全）
- [ ] 人工可读性评分 ≥ 4/5（或达标基线）

## 技术决策

### 决策 1：报告格式
- **选择**：Markdown 为主 + HTML 增强
- **理由**：Markdown 天然适配代码仓库与模板；HTML 便于图表渲染与展示

### 决策 2：生成策略
- **选择**：模板填充 + LLM 润色（两阶段）
- **理由**：模板保证结构稳定与证据约束，LLM 只做语言润色，避免整篇生成导致幻觉
