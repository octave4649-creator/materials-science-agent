# 20260806 开发计划

## 1. 项目定位

**方向**：方向三·材料科学文献驱动的科学发现智能体
**核心领域**：无机材料（热电/催化/电池材料）—— 已有完整管线
**拓展领域**：生物材料——酵母蛋白质组学（WAYB/WAYC 数据集）—— 跨域验证实验
**进阶路线**：路线 A——构效关系发现

### 1.1 双轨策略

| 轨道 | 领域 | 数据集 | 状态 | 说明 |
|------|------|--------|------|------|
| **主线（核心交付）** | 无机材料 | 材料科学文献 + Materials Project/OQMD | 已有管线 | 已完成文献检索/抽取/Gap识别/GA/MCTS/BO搜索/数据库验证 |
| **拓展（加分实验）** | 生物材料 | WAYB/WAYC 酵母蛋白质组学 | 待开发 | 作为跨域验证，证明管线通用性 |

**决策原则**：主线为必交付物，拓展为加分项。若拓展开发影响主线质量，优先保障主线。

## 2. 数据集概要

### 2.1 WAYB/WAYC 数据结构

| 维度 | 取值 | 说明 |
|------|------|------|
| 样本总数 | 13,412 | train(5920) + val_strain_only(1547) + val_chem_only(1065) + val_both(269) + val_time(157) + test(4454) |
| 菌株 | 5 种 | BAI, BAH, DHY210, CEK, CGD |
| 温度 | 2 种 | 30°C, 37°C |
| 培养基 | 2 种 | YNB+CSM+2% glucose, YNB+CSM+2% galactose |
| 化学扰动 | 41 种 | pert_id: #1 ~ #41 |
| 蛋白特征 | 5243 维 | 基因表达量（如 AAC1, ZWF1 等酵母基因） |

### 2.2 生物材料映射关系

| 传统材料概念 | 生物材料对应 | 本项目具体值 |
|-------------|-------------|-------------|
| 材料 | 酵母菌株 | 5 种菌株（BAI/BAH/DHY210/CEK/CGD） |
| 成分描述符 | 基因表达谱 | 5243 维蛋白表达量 |
| 合成条件 | 培养条件 | 温度/碳源/化学扰动 |
| 材料性能 | 菌株响应 | 特定条件下的基因表达变化模式 |
| 构效关系 | 基因表达→性能 | 表达模式→菌株适应性/功能 |

## 3. 开发任务分解

### 阶段一：数据准备与预处理（优先级：最高）

| 任务 | 产出 | 状态 | 依赖 |
|------|------|------|------|
| T1.1 WAYB/WAYC 数据加载器 | `src/proteome/data_loader.py` | ✅ 已完成 | 无 |
| T1.2 数据清洗与归一化 | `src/proteome/preprocessor.py` | ✅ 已完成 | T1.1 |
| T1.3 特征工程 | `src/proteome/feature_engineering.py` | ✅ 已完成 | T1.2 |
| T1.4 数据划分验证 | `src/proteome/split_validator.py` | ✅ 已完成 | T1.1 |

**T1.1 数据加载器需求**（✅ 已实现）：
- 读取 metadata CSV（15 列）和 proteome CSV（5244 列）
- 通过 sample_ID 关联 metadata 与表达数据
- 按 split 划分 train/val/test（支持单 split 和多 split 过滤）
- 输出结构化的 ProteomeDataset 对象（含样本列表、基因名列表、聚合方法）
- 已实现 `compute_strain_conditions()` 聚合菌株-条件级表达统计
- 已实现 `get_expression_matrix()` 输出样本×基因矩阵
- 复用 `config.py` 路径管理、`AuditLogger` 审计日志
- BioCandidate 兼容现有 Candidate 接口（score_avg/to_dict）
- 测试覆盖：21 单测全通过，ruff 零报错

**T1.2 数据清洗需求**（✅ 已实现）：
- 处理缺失值（zero/median/mean 三种策略）
- 对数转换（log2 transform，含负值处理与零值位移）
- 批次效应检测与校正（基于 replicate 组的均值中心化）
- 特征方差过滤（去除低方差特征）
- 一键管线 `preprocess()`，输出 PreprocessReport 审计
- 测试覆盖：17 单测全通过

**T1.3 特征工程需求**（✅ 已实现）：
- 按 菌株×温度×培养基×扰动 聚合表达量（复用 data_loader 的 compute_strain_conditions）
- 计算差异表达量（log2FC，含 pseudocount 防除零）
- 提取功能蛋白家族特征（HSP/代谢/氧化应激/DNA修复四大类，60+ 基因映射）
- 构建菌株-条件级别的材料描述符向量（BioFeatureDescriptor）
- 两种对照组策略：same_strain_baseline / same_condition_baseline
- 测试覆盖：13 单测全通过

**T1.4 数据划分验证需求**（✅ 已实现）：
- 划分互斥性检查（每个样本只属于一个 split）
- 划分覆盖率检查（所有样本分配到合法 split）
- 与预期样本数比较（容差 20%，对齐 00-rules 5.3 节）
- 菌株分布统计（每个 split 的菌株分布表）
- 化学扰动分布统计
- 数据泄漏检测（train/test 的 (strain, pert_id) 交集）
- val_strain_only 含未训练菌株、val_chem_only 含未训练扰动的一致性检查
- Markdown 报告生成器（generate_split_summary）
- 测试覆盖：17 单测全通过

| 任务 | 产出 | 状态 | 依赖 |

**T2.1 文献检索**（✅ 已完成）：
- 关键词扩展器 `src/proteome/query_expander.py`：7 类关键词 + 6 个 Gap 方向布尔查询模板 + 中英文双语
- 检索适配器 `src/proteome/bio_retrieval.py`：
  - `BioRetrievalAgent` 复用 RetrievalAgent（依赖注入，CI 可 mock）
  - `run_gap_search()` 按 6 个 Gap 方向批量调度 Sciverse 双通道检索
  - 跨方向去重（复用 `RetrievalAgent._dedupe_key`，可关闭）
  - 证据链合并（各方向 EvidenceItem 汇总到总 EvidenceChain）
  - `run_strain_search()` 按菌株-条件组合检索（build_research_question）
  - `search_and_save()` 一键检索+落盘，`BioRetrievalReport.save()` 写 JSON
  - 单方向失败降级为 failed 状态，不中断流水线（exp.md 经验 26）
- 运行脚本 `scripts/run_bio_retrieval.py`：支持 --directions/--top-k/--year-from/--mode/--output
- 测试覆盖：17 单测全通过（FakeRetrievalAgent 注入，零网络依赖）
- 下一步：T2.2 生物材料知识抽取（对 chunk 证据做 LLM schema 抽取，构建生物材料知识库）

**T2.2 知识抽取**（✅ 已完成）：
- 实现模块 `src/proteome/bio_extraction.py`：
  - Schema：`BioCondition`（菌株/温度/碳源/扰动）+ `ProteinFamilyEntry`（家族/基因/响应）+ `BioResponse`（方向/描述/表型）+ `BioKnowledgeEntry`（复用 `SourceRef`，接口契约对齐 `ExtractionRecord`，exp.md 经验 58）
  - `BioKnowledgeBase`：落库 `data/bio_kb.json`，去重键 = 菌株|温度|碳源|扰动|响应方向，同键合并蛋白家族并集 + 证据回链（exp.md 经验 81）
  - `BioExtractionAgent`：复用 ExtractionAgent 模式（LLM 优先 → 失败降级规则式 → 回查防幻觉 → 落库）
  - 防幻觉三件套（exp.md 经验 13）：schema 约束 + 原文回查「三选一」（菌株名/基因名/响应关键词至少一个在原文，exp.md 经验 79）+ 证据链接（doc_id 注入）
  - 规则式降级：正则匹配菌株/温度/碳源 + 遍历 `PROTEIN_FAMILIES` 找命中基因 + `RESPONSE_KEYWORDS` 关键词推断响应方向（exp.md 经验 82）
  - 加载层宽容：`BioCondition.strain` 验证器只做大写归一化，非法值原样保留留给下游校验（exp.md 经验 78）
  - 子对象 None 容错：`BioResponse.direction` 设默认值 + 父字段验证器 None→空对象（exp.md 经验 80）
- 运行脚本 `scripts/run_bio_extraction.py`：默认读最新 `results/bio_retrieval_*.json`，输出 `data/bio_kb.json`
- 测试覆盖：28 单测全通过（mock LLM 工厂函数模式，零网络依赖，exp.md 经验 83）
- 质量门禁：ruff check 零报错；全量回归 pytest 271 passed（未破坏其他模块）
- 下一步：T2.3 Research Gap 识别（基于 bio_kb.json 做覆盖率分析 + LLM 推理，生成生物材料版 Gap 清单）

## 6. 风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| **领域错配（高）** | 生物材料映射可能不被评委认可，分散主线开发精力 | 生物材料定位为「跨域验证」而非主线；保留「材料→生物材料」的类比论证（菌株=生物功能材料，基因表达=成分描述符）；截止日期前若无法形成有力交叉论证则回退 |
| 5243 维特征过高维 | 搜索空间爆炸 | 先用方差过滤降至 500-1000 维，再按功能分组 |
| LLM 生物学评估幻觉 | 错误评估候选合理性 | 规则校验（UniProt/GO 注释）+ 文献回查双重验证 |
| 数据库 API 限流 | 验证中断 | 批量查询+缓存+降级为本地 UniProt 离线库 |
| 菌株-条件组合稀疏 | 部分组合无数据 | 合理缺失处理：标记为不可达区域，不强行插值 |
| 功能蛋白注释不全 | 特征工程受限 | 先用 UniProt 现有注释，未注释蛋白标记为「功能未知」 |

### 6.1 拓展实验熔断机制

若出现以下任一情况，立即暂停生物材料拓展开发，全部资源回归主线：
1. 主线评测未通过（召回率 < 0.5）
2. 拓展实验开发时间超过总开发时间的 30%
3. 无法在生物材料与无机材料之间建立有说服力的交叉论证
4. 距离提交截止不足 3 天
