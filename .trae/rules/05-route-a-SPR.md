# 路线A·构效关系发现

## 1. 路线定位

基于文献调研 Agent 产出的 Research Gap 与知识库，结合开源材料数据库，发掘具有新颖性和可信性的构效关系（Structure-Property Relationship，SPR），并提供可信的科学解释。占进阶路线 50% 评分。

**本项目生物材料定位**：将 SPR 框架从传统无机材料拓展到**生物材料——酵母菌株**：
- **材料**：5 种酵母菌株（BAI、BAH、DHY210、CEK、CGD）= 5 种「生物功能材料」
- **成分描述符**：5243 维蛋白表达谱 = 「材料成分/结构特征」
- **合成加工条件**：温度(30/37°C)、培养基(葡萄糖/半乳糖)、41 种化学扰动 = 「材料制备/使用条件」
- **性能**：菌株在特定条件下的响应/适应 = 「材料性能」
- **构效关系**：基因表达模式 → 菌株条件响应的关系 = 「基因表达-性能构效关系」

## 2. 核心要求

1. **搜索算法必须与 LLM 深度融合**：不能用 LLM 只生成搜索代码，要考察 LLM 参与搜索过程本身
2. **证据链支撑**：发现的构效关系须有文献证据链，区分「新知」与「已知」
3. **数据库交叉验证**：鼓励与 Materials Project、OQMD、NOMAD 等公开数据库交叉验证
4. **可解释性**：须附带清晰科学解释，避免「黑箱输出」
5. **领域理解**：对细分领域（热电、催化、电池材料等）有深刻理解

## 3. LLM 与搜索算法深度融合模式

### 3.1 LLM 参与搜索的三个关键角色

| 角色 | 作用 | 实现方式 |
|------|------|---------|
| 假设种子生成器 | 生成候选假设作为搜索种群种子 | LLM 基于 Research Gap 生成初始候选（成分/结构假设） |
| 科学合理性评估器 | 评估中间结果的科学合理性 | LLM 对搜索结果打分：热力学可行性、物理合理性、文献支持度 |
| 搜索空间引导器 | 引导搜索空间剪枝与聚焦 | LLM 根据中间结果反馈，调整搜索方向/参数区间 |

### 3.2 推荐框架：搜索循环

```
1. LLM 生成初始候选假设集合（种子种群）
2. 搜索算法（GA/MCTS/BO/SR）在候选空间迭代探索
3. LLM 评估中间结果的科学合理性 → 过滤明显不合理候选
4. LLM 分析搜索反馈 → 剪枝/聚焦搜索空间
5. 收敛后：LLM 对最终构效关系做科学解释与文献对照
6. 数据库交叉验证（MP/OQMD/NOMAD）
```

## 4. 搜索优化算法

### 4.1 算法对比与选型

| 算法 | 原理 | 优点 | 适用场景 |
|------|------|------|---------|
| 遗传算法 (GA) | 选择/交叉/变异演化 | 全局搜索能力强、实现简单 | 组合材料空间（成分/掺杂） |
| 蒙特卡洛树搜索 (MCTS) | 树搜索 + 模拟评估 | 擅长序贯决策、LLM 天然适配 | 结构设计、多步合成路径 |
| 贝叶斯优化 (BO) | 代理模型 + 采集函数 | 采样效率高、适合昂贵评估 | 性能-参数连续空间优化 |
| 符号回归 (SR) | 演化符号表达式 | 产出可解释的数学表达式 | 解析式构效关系发现 |

### 4.2 LLM + 搜索算法结合要点

- **GA + LLM**：LLM 生成初始种群、评估适应度、解释最优个体
- **MCTS + LLM**：LLM 作为节点扩展器（生成候选子节点）与价值评估器（评估节点优劣）
- **BO + LLM**：LLM 定义搜索空间维度、解析采集函数建议、生成下一轮候选
- **SR + LLM**：LLM 生成符号表达式候选、筛选物理合理项

### 4.3 参考实现

- **CheMatAgent**（arXiv:2506.07551）：Hierarchical Evolutionary MCTS（HE-MCTS）框架，137 个化学工具，高/低层策略模型分别优化工具规划与执行
- **dZiner**（arXiv:2410.03963）：LLM 智能体逆向设计，结合文献领域知识与代理模型迭代评估，含合成可行性评估
- **MatAgent**（arXiv:2504.00741）：生成式 AI 智能体无机材料设计

## 5. 构效关系挖掘流程

### 5.1 输入

- 文献调研 Agent 产出的知识库（成分-结构-性能三元组 + 证据链）
- 选定细分领域与目标性能（如热电优值 ZT、催化活性、带隙）

### 5.2 挖掘步骤

1. **特征定义**：定义材料表示（成分、结构描述符、合成参数）
2. **候选生成**：LLM + 搜索算法在特征空间生成候选
3. **评估**：代理模型预测性能 + LLM 科学合理性评估
4. **筛选**：过滤不可行候选，保留高潜力候选
5. **数据库验证**：MP/OQMD/NOMAD 查询验证
6. **文献对照**：与文献既有结论比较，区分新知与已知
7. **解释输出**：生成科学的构效关系陈述 + 机制解释

### 5.3 输出格式（构效关系清单）

```
构效关系条目
├─ 关系陈述：如「A 位掺杂半径增大 → 钙钛矿带隙单调减小」
├─ 证据链：文献证据（DOI）+ 数据库验证（MP material_id）
├─ 与已有结论的关系：新知/已知/部分争议
├─ 科学解释：物理/化学机制
└─ 置信度与适用范围（成分/温度/压力区间）
```

## 6. 生物材料构效关系发现流程（新增）

### 6.1 WAYB/WAYC 数据集 SPR 框架

```
输入：WAYB/WAYC 蛋白质组学数据集
处理流程：
1. 数据加载 → 5 种菌株 × 41 扰动 × 5243 蛋白表达量
2. 特征工程 → 将 5243 维表达量聚合为菌株-条件描述符
3. 搜索空间定义 → 菌株 × 温度 × 培养基 × 扰动条件的组合空间
4. LLM 种子生成 → 基于文献 Gap 生成候选构效关系假设
5. 搜索算法探索 → GA/MCTS 在组合空间中发现基因表达-性能关联
6. LLM 评估 → 评估发现的生物学合理性（代谢通路、蛋白功能）
7. 数据库验证 → UniProt/YeastMine/SGD 交叉验证
8. 文献对照 → 区分「已知生物学知识」与「新发现关联」
输出：基因表达-性能构效关系清单
```

### 6.2 生物材料特有的搜索维度

| 维度 | 取值 | 搜索意义 |
|------|------|---------|
| 菌株（Strain） | BAI, BAH, DHY210, CEK, CGD | 遗传背景差异 |
| 温度 | 30°C, 37°C | 温度响应机制 |
| 碳源 | 葡萄糖, 半乳糖 | 代谢通路切换 |
| 扰动 | #1-#41 | 化学扰动响应 |
| 蛋白特征 | 5243 维 | 分子层面机制 |

### 6.3 生物材料 SPR 输出格式

```
生物材料构效关系条目
├─ 关系陈述：如「高温(37°C) + 半乳糖条件下，菌株 BAI 的热休克蛋白家族(HSP70/HSP90)表达上调 → 耐热性增强」
├─ 证据链：
│   ├─ 文献证据（DOI: xxx，页码 p.y）
│   ├─ 数据验证（UniProt: HSP70_SCE 功能注释）
│   └─ 数据库验证（YeastMine: BAI 菌株 37°C 生长曲线）
├─ 与已有结论的关系：新知/已知/部分争议
├─ 科学解释：分子机制（热休克响应通路、代谢重编程）
└─ 置信度与适用范围（菌株×温度×碳源的适用区间）
```

### 6.4 关键 Research Gap 候选

基于 WAYB/WAYC 数据特点，以下方向可能存在未被充分研究的 Gap：

1. **菌株×温度交互效应**：5 种菌株在 30°C vs 37°C 下的蛋白表达差异模式
2. **碳源切换的代谢响应**：葡萄糖→半乳糖切换时的蛋白表达重编程
3. **化学扰动的菌株特异性**：同一扰动在不同菌株中的响应差异
4. **温度-碳源-扰动的三方交互**：多条件组合下的基因表达模式
5. **功能蛋白家族的表达聚类**：特定功能（如氧化应激、DNA修复）的蛋白协同表达
