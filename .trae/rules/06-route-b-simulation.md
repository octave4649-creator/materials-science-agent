# 路线B·模拟方法创新

## 1. 路线定位

改进材料科学中的计算方法，在保证精度的前提下提升模拟效率。占进阶路线 50% 评分。适合有计算材料/DFT/MD 背景的团队。

## 2. 可探索方向

| 方向 | 具体内容 |
|------|---------|
| DFT 计算加速与改进 | 密度泛函理论计算加速、交换关联泛函改进、赝势优化 |
| 蒙特卡洛模拟效率提升 | 采样策略改进、多尺度 MC 方法 |
| 分子动力学（MD）新架构 | 机器学习势函数、粗粒化模型、多尺度耦合 |
| 生成式模型替代模拟 | 扩散模型、流模型替代或增强传统模拟方法 |
| 前沿方法 | 变分蒙卡、张量网络、神经架构搜索（NAS） |

## 3. 机器学习势函数（ML Potential）

### 3.1 代表模型

| 模型 | 特点 | 适用 |
|------|------|------|
| MACE | 等变消息传递 + 多体描述 | 高精度能量/力预测、通用体系 |
| NequIP | 等变神经网络势函数 | 小数据集高精度、分子/材料 |
| CHGNet | 电荷-感知神经网络势函数 | 带电体系、离子迁移、电池材料 |

### 3.2 与 LLM 智能体结合

- LLM 编排模拟工作流：任务定义 → 参数设置 → 结果分析
- LLM 调用 ML 势函数工具完成结构优化、MD 模拟
- 多智能体分工：如 ChatMat 的 Computing Designer / DFT Operator / ML-PES Performer 分工

## 4. 评测基准（Benchmark）

### 4.1 公认 Benchmark

| Benchmark | 内容 | 考察点 |
|-----------|------|--------|
| MD17 | 分子动力学轨迹数据（8 个分子体系） | 力/能量预测精度 |
| QM9 | 13.4 万有机分子量子化学数据 | 性质预测、生成模型 |
| Materials Project 轨迹 | 晶体材料结构与性质数据 | 材料性质预测 |

### 4.2 评估要点

- 公认 benchmark 上的表现（精度）
- 细分领域的优异之处（如特定材料相变模拟精度提升）
- 模拟效率与精度保持之间的权衡
- 方法的可复现性

## 5. 加分项

- 有实验验证结果
- 在真实材料体系上展示实用价值

## 6. 参考系统

- **VASPilot / PhysAgent**：多智能体计算材料学系统，实现结构建模、参数设置到结果分析的全流程自动化
- **ChatMat**（Digital Discovery 2026）：多智能体化学家，Manager 协调 Property Depositor、Computing Designer、DFT Operator、ML-PES Performer
- **Aitomia**（厦门大学）：ML 驱动化学计算 Agent 平台，速度较传统 DFT 提升 10-100 倍

## 7. 评估要点自检清单

- [ ] 是否在公认 benchmark（MD17/QM9/MP 轨迹）上有量化表现
- [ ] 是否有细分领域的改进幅度数据
- [ ] 是否权衡了模拟效率与精度
- [ ] 方法是否可复现（代码/配置/随机种子完整）
- [ ] 是否有实验验证或真实体系实用价值（加分）
