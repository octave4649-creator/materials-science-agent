# 路线C·合成路线与工艺设计

## 1. 路线定位

基于文献调研发现的 Research Gap，构建能够生成合成路线或优化合成工艺的智能体系统。占进阶路线 50% 评分。适合有化学合成/工艺背景的团队。

## 2. 三大核心任务

### 2.1 合成路线生成

给定目标材料，自动生成可行的合成路线：

| 要素 | 内容 |
|------|------|
| 前驱体选择 | 选择合适的前驱体原料 |
| 反应条件 | 温度、压力、时间、气氛、溶剂 |
| 步骤顺序 | 反应步骤的合理编排 |
| 文献依据 | 每条路线/步骤给出文献支撑 |

### 2.2 工艺优化

针对现有合成工艺提出改进方案：

- 产率提升
- 条件简化（降低温度/压力要求）
- 成本降低
- 环境友好性改进

### 2.3 合成验证

通过文献追溯、计算模拟或实验验证实现生成路线的可验证性。

## 3. 逆向合成分析（Retrosynthesis）与 LLM 结合

### 3.1 方法

- **逆向合成分析**：从目标分子/材料出发，逆向分解为更简单的前体
- **LLM 推理结合**：LLM 基于化学知识与文献，生成逆向合成路线候选
- **反应规则库**：结合反应数据库（如化学反应数据库、专利数据）验证反应步骤可行性

### 3.2 参考系统

- **ChemCrow**（洛桑联邦理工/罗切斯特大学）：集成 18 种专业化学工具，覆盖有机合成、药物发现与材料设计；基于 GPT-4 构建，低幻觉高准确率化学推理，可自主规划并执行化学反应
- **MOSAIC**（耶鲁/勃林格殷格翰）：模块化合成 AI 系统，专精复杂分子逆向合成，分步合成指令可直接供自动化系统执行

### 3.3 LLM Agent 合成路线生成流程

```
1. 输入目标材料（成分/结构/性质目标）
2. LLM 从文献知识库检索相关合成报道（前驱体、条件、产率）
3. 逆向合成分解：LLM 生成合成树候选
4. 反应可行性评估：LLM + 反应规则/数据库校验每步反应
5. 条件优化：LLM 建议关键工艺参数区间
6. 输出：合成路线 + 文献依据 + 推理过程说明
```

## 4. 核心要求

1. **推理过程可见**：系统须能展示为什么选择这条路线/这个条件
2. **文献/原理支撑**：合成建议须有文献或化学原理支撑，不能凭空生成
3. **可验证性**：生成路线可通过文献追溯、计算模拟或实验验证

## 5. 数据资源

- 合成条件数据可从文献知识库抽取（见 [[基础任务·文献调研 Agent]] 知识抽取方案）
- 反应验证可借助化学反应数据库与专利数据（Sciverse 含 7000 万专利记录）
- 可参考 MolAid（30 亿+ 生化分子数据、8000 万+ 反应数据）类平台思路

## 6. 加分项

- 有实验验证结果
- 对现行工艺实现了可量化的优化

## 7. 评估要点自检清单

- [ ] 合成路线是否可行（步骤、前驱体、条件合理）
- [ ] 优化方案是否有效（量化改进指标）
- [ ] 验证手段是否充分（文献/计算/实验）
- [ ] 推理过程是否可见（为什么选这条路线的解释）
- [ ] 是否有文献或化学原理支撑（非凭空生成）
