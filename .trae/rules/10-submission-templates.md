# 提交材料模板

## 1. 三阶段提交总览

| 阶段 | 截止时间 | 必交材料 |
|------|---------|---------|
| 初赛 | 8.16 | 方案说明文档、技术路线概述 |
| 复赛 | 9.3 | 可运行代码仓库、实验结果报告、科学意义阐释、依赖披露 |
| 决赛 | 9.22 | 海报/路演材料、现场展示、最终代码仓库、项目一页纸 |

## 2. 初赛 · 方案说明文档模板（≤4 页）

### 2.1 问题定义文档结构

```
# 材料文献智能体 · 问题定义文档

## 1. 问题真实性（问题确实存在且重要）
- 所选细分领域（如热电材料/催化/电池材料）
- 该领域真实未解问题或研究瓶颈
- 问题重要性（对材料科学/产业的意义）

## 2. AI 介入点
- AI 在解决该问题中的关键作用（文献挖掘/构效关系/合成设计/模拟加速）
- 为什么 AI 方法优于/补充传统方法

## 3. 探索环境
- 数据来源（Sciverse/Sci-Base/Materials Project 等）
- 工具链（MCP、MinerU、pymatgen 等）
- 计算资源与运行方式

## 4. 发现信号
- 如何判定「发现」发生（Gap 新颖性指标/构效关系验证/性能提升）
- 最小验证标准（可量化）

## 5. 最小参照系
- 与已有方法/基准的对标（基准线）
- 团队已有基础与差异化优势
```

### 2.2 技术路线概述要点

- 所选方向（方向三）+ 路线（A/B/C）
- 科学问题理解（一句话说明）
- 技术方案（架构图 + 模块说明）
- 方法路线（搜索算法 × LLM 融合方式）
- 预期成果与风险评估

## 3. 复赛 · 实验报告与代码仓库模板

### 3.1 文献调研报告模板（基本任务交付物）

```
# 文献调研报告

## 1. 研究问题与范围
## 2. 检索策略与数据来源
   - 检索关键词、检索时间、检索记录（Sciverse 调用日志）
## 3. 知识抽取结果
   - 结构化数据表（成分/结构/性能/方法/条件）
## 4. Research Gap 清单
   - 每个 Gap：描述 / 证据链（DOI+页码）/ 文献交叉引用 / 潜在研究方向
## 5. 文献综述
## 6. 结论与建议
## 附录：文献清单（DOI、标题、来源记录 ID）
```

### 3.2 代码仓库结构（提交要求）

```
your-project/
├── README.md               # 项目简介、安装、快速开始
├── requirements.txt        # 依赖清单（含版本）
├── config/                 # 配置文件（API Key 用环境变量）
├── src/                    # 源码
│   ├── agent/              # Agent 编排
│   ├── retrieval/          # 文献检索
│   ├── extraction/         # 知识抽取
│   ├── search/             # 搜索算法（路线A）
│   └── report/             # 报告生成
├── data/                   # 数据（或数据获取脚本）
├── scripts/                # 运行脚本
├── results/                # 实验结果
└── docs/                   # 文档
```

### 3.3 代码仓库清单（Checklist）

- [ ] README：项目简介、环境要求、安装步骤、快速开始示例
- [ ] requirements.txt：完整依赖与版本锁定
- [ ] API Key 通过环境变量配置，不硬编码、不入库
- [ ] 随机种子固定，结果可复现
- [ ] 提供运行入口（`python run.py` 或 `bash run.sh`）
- [ ] 提供结果复现说明（命令级复现）
- [ ] LICENSE 文件明确开源协议
- [ ] 依赖/授权披露：商业 API、外部数据、许可证、关键版本

## 5. 决赛 · 展示材料模板

### 5.1 项目一页纸

```
# 项目名称
- 一句话简介
- 科学问题
- 方法与创新点（3 条以内）
- 核心结果（量化）
- 团队与开源仓库
```

### 5.2 海报/路演结构

1. 问题背景与意义（1 屏）
2. 技术架构与创新点（2 屏）
3. 核心结果与证据链（2 屏）
4. 科学意义与展望（1 屏）
