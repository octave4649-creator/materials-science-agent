# 赛题规则与评审标准

## 1. 赛题结构

```
方向三：材料科学文献驱动的科学发现智能体
├── 基本任务（必做，占材料方向评分 50%）：文献调研 Agent
│   检索筛选 → 知识抽取 → Gap 识别 → 报告生成
└── 进阶路线（三选一，占 50%）
    ├── 路线A：构效关系发现（搜索算法 × LLM 深度融合 + 数据库交叉验证）
    ├── 路线B：模拟方法创新（DFT/MD/MC 加速 + ML 势函数 + benchmark）
    └── 路线C：合成路线与工艺设计（逆向合成 × LLM + 工艺优化）
```

## 2. 评审维度

| 维度 | 权重 | 材料方向含义 |
|------|------|-------------|
| 技术性能 | 45% | 基本任务 50% + 进阶路线 50% 综合分 |
| 科学意义 | 30% | 发现的 Gap/构效关系是否真实、超出已有边界 |
| 方法创新性 | 20% | 搜索方法与 LLM 深度融合（非简单集成） |
| 开源贡献 | 5% | 代码、模型、管线开源质量 |

## 3. 核心红线

1. **证据链可审计**：每个结论可回溯到「来源 + DOI + 页码 + 调用时间」
2. **搜索 × LLM 深度融合**：LLM 参与生成候选/评估合理性/引导剪枝，而非仅写代码
3. **科学意义靠选题**：深耕单一细分领域（热电/催化/电池/固态电解质），避免空泛

## 4. 赛程时间线

| 节点 | 时间 |
|------|------|
| 初赛提交截止 | 8.16（方案说明文档 ≤4 页，不强制代码） |
| 复赛入围公布 | 8.24（Top 40） |
| 复赛提交截止 | 9.3（代码仓库 + 实验报告 + 依赖披露） |
| 决赛入围公布 | 9.10（Top 20） |
| 决赛 | 9.22（海报 + demo + 一页纸） |

## 5. 合规红线

- 商业 API/闭源模型须披露：调用环节、费用假设、可替代性、对复现性影响
- 外部数据登记授权（Sci-Base CC-BY-4.0；MP/OQMD 使用条款）
- 派生项目说明来源、贡献范围、新增创新点
- 复赛仓库：README、环境配置、随机种子、LICENSE、依赖版本

## 6. 推荐工具（官方）

- Sciverse 科学智能数据库（MCP 接入天然构成证据链）
- MinerU 文档解析引擎
- Materials Project / OQMD / NOMAD（路线 A 交叉验证）
