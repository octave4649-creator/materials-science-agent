# 路线C：合成路线与工艺设计

## 1. 路线定位

基于文献调研发现的 Research Gap，构建生成合成路线或优化合成工艺的智能体系统。占进阶路线 50% 评分。适合有化学合成/工艺背景的团队。

## 2. 三大核心任务

| 任务 | 内容 |
|------|------|
| 合成路线生成 | 前驱体选择、反应条件（温度/压力/时间/气氛/溶剂）、步骤顺序、文献依据 |
| 工艺优化 | 产率提升、条件简化、成本降低、环境友好 |
| 合成验证 | 文献追溯 / 计算模拟 / 实验验证 |

## 3. 逆向合成 × LLM 结合

- **逆向合成分解**：从目标材料逆向分解为简单前体
- **LLM 推理**：基于化学知识与文献生成合成树候选
- **反应规则库**：结合化学反应数据库验证步骤可行性

```
1. 输入目标材料（成分/结构/性质目标）
2. LLM 检索文献知识库相关合成报道
3. 逆向合成分解：LLM 生成合成树候选
4. 反应可行性评估：LLM + 反应规则/数据库校验
5. 条件优化：LLM 建议工艺参数区间
6. 输出：合成路线 + 文献依据 + 推理过程
```

## 4. 核心要求

1. **推理过程可见**：展示为什么选这条路线/条件
2. **文献/原理支撑**：不能凭空生成
3. **可验证性**：可通过文献追溯、计算模拟或实验验证

## 5. 参考系统

- **ChemCrow**（arXiv:2304.05376）：18 种化学工具，有机合成/药物/材料
- **MOSAIC**：复杂分子逆向合成，分步指令可自动化执行
- **MolAid**：30 亿+ 分子、8000 万+ 反应数据平台

## 6. 数据资源

- 合成条件从文献知识库抽取（见技能 `literature-agent`）
- 反应验证可借助 Sciverse（含 7000 万专利记录）

## 7. 加分项

- 有实验验证结果
- 对现行工艺实现可量化优化
