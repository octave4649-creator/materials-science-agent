# 提交材料模板

## 1. 三阶段提交总览

| 阶段 | 截止 | 必交材料 |
|------|------|---------|
| 初赛 | 8.16 | 方案说明文档、技术路线概述（≤4 页，不强制代码） |
| 复赛 | 9.3 | 可运行代码仓库、实验报告、科学意义阐释、依赖披露 |
| 决赛 | 9.22 | 海报/路演、现场展示、最终代码仓库、项目一页纸 |

## 2. 初赛问题定义文档模板

```
## 1. 问题真实性
- 所选细分领域（热电/催化/电池/固态电解质）
- 真实未解问题与研究瓶颈
## 2. AI 介入点
- AI 的关键作用 + 为什么 AI 优于传统方法
## 3. 探索环境
- 数据来源（Sciverse/Sci-Base/MP）、工具链、计算资源
## 4. 发现信号
- 判定「发现」发生的指标（Gap 新颖性/构效关系验证/性能提升）
## 5. 最小参照系
- 与已有方法/基准对标 + 团队差异化优势
```

## 3. 复赛交付物

### 代码仓库结构

```
├── README.md            # 简介、安装、快速开始
├── requirements.txt     # 依赖锁定
├── src/                 # agent/retrieval/extraction/gap/search/validation/report
├── scripts/             # 运行脚本
├── results/             # 实验结果
└── docs/                # 文档
```

### 自查清单

- [ ] README 含环境要求、安装步骤、快速开始、复现说明
- [ ] requirements.txt 版本锁定
- [ ] API Key 走环境变量，不入库
- [ ] 随机种子固定可复现
- [ ] LICENSE 文件明确协议
- [ ] 依赖/授权披露完整

## 4. 依赖披露模板

```
### 开源依赖      | 依赖 | 版本 | 许可证
### 商业API/闭源  | 服务 | 用途 | 费用假设 | 可替代性
### 外部数据      | 数据集 | 来源 | 授权协议
### 已有项目      | 来源、贡献范围、新增创新点、协议兼容性
```

## 5. 决赛展示

- 项目一页纸：一句话简介 + 科学问题 + 方法与创新点（≤3 条）+ 核心结果（量化）+ 团队与仓库
- 海报：问题背景→技术架构→核心结果与证据链→科学意义

## 6. 撰写要点

- 初赛：写作优先级高于代码，突出问题真实性与方案清晰度
- 证据链完整是通吃要求，报告中每个结论可回溯
- 负结果也有价值（说明探索真实）
