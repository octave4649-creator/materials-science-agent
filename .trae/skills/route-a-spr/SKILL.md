# 路线A：构效关系发现

## 1. 路线定位

基于 Research Gap 与知识库，结合开源材料数据库，发掘具有新颖性和可信性的构效关系（Structure-Property Relationship），并提供可信科学解释。占进阶路线 50% 评分。

## 2. 核心要求（评审红线）

1. **搜索算法必须与 LLM 深度融合**（创新性 20% 的主战场）
2. 构效关系须有文献证据链，区分「新知」与「已知」
3. 鼓励与 Materials Project / OQMD / NOMAD 交叉验证
4. 附带清晰科学解释，避免黑箱输出

## 3. LLM × 搜索算法三角色融合

| 角色 | 作用 | 实现 |
|------|------|------|
| 假设种子生成器 | 基于 Gap 生成候选假设作搜索种群种子 | LLM 生成候选掺杂/结构假设 |
| 科学合理性评估器 | 评估中间结果合理性 | 打分：热力学可行、物理合理、文献支持 |
| 搜索空间引导器 | 根据反馈剪枝/聚焦 | 淘汰低潜力方向 |

## 4. 推荐发现闭环

```
1. LLM 生成初始候选假设（基于 Gap 与知识库）
2. 搜索算法（GA/MCTS/BO/SR）迭代探索
3. LLM 评估中间结果 → 过滤不合理候选
4. LLM 剪枝/聚焦搜索空间
5. 收敛后：LLM 生成构效关系解释 + 文献对照
6. 数据库交叉验证（MP/OQMD/NOMAD）
7. 输出构效关系清单：陈述 + 证据链 + 新知/已知 + 机制解释
```

## 5. 算法选型

| 算法 | 工具 | 适用 |
|------|------|------|
| 遗传算法 GA | DEAP | 组合材料空间（掺杂/组分） |
| MCTS | 自研 | 序贯决策，LLM 扩展器/评估器 |
| 贝叶斯优化 BO | skopt/optuna | 连续参数空间 |
| 符号回归 SR | gplearn | 可解释解析表达式 |

## 6. 交叉验证

文献抽取 → 数据库查询 → 一致性检查 → 新颖性判断 → 证据链记录。指标：生成能一致性、带隙区间重叠度、hull 距离。
