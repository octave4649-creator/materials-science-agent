# 路线B：模拟方法创新

## 1. 路线定位

改进材料科学中的计算方法，在保证精度的前提下提升模拟效率。占进阶路线 50% 评分。适合有计算材料/DFT/MD 背景的团队。

## 2. 可探索方向

| 方向 | 内容 |
|------|------|
| DFT 加速与改进 | 泛函改进、赝势优化、加速算法 |
| 蒙特卡洛效率提升 | 采样策略、多尺度 MC |
| MD 新架构 | ML 势函数、粗粒化、多尺度耦合 |
| 生成式模型 | 扩散模型/流模型替代或增强模拟 |
| 前沿方法 | 变分蒙卡、张量网络、NAS |

## 3. 机器学习势函数

| 模型 | 特点 | 适用 |
|------|------|------|
| MACE | 等变消息传递 + 多体描述 | 高精度通用 |
| NequIP | 等变神经网络势函数 | 小数据集高精度 |
| CHGNet | 电荷感知势函数 | 带电体系、电池材料 |

**LLM 结合**：LLM 编排模拟工作流（任务→参数→结果分析），多智能体分工（如 ChatMat：Computing Designer / DFT Operator / ML-PES Performer）。

## 4. 评测基准

| Benchmark | 内容 | 考察点 |
|-----------|------|--------|
| MD17 | 分子动力学轨迹 | 力/能量精度 |
| QM9 | 13.4 万有机分子 | 性质预测 |
| MP 轨迹 | 晶体材料数据 | 材料性质预测 |

**评估**：benchmark 表现 + 细分领域改进幅度 + 效率/精度权衡 + 可复现性。

## 5. 加分项

- 有实验验证结果
- 在真实材料体系上展示实用价值
