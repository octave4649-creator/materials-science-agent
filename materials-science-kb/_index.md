# 材料科学文献驱动的科学发现智能体 · 知识库导航

本知识库服务于 GOAI 赛道三【前沿探索 AI for Research】方向三——「材料科学文献驱动的科学发现智能体」，按四层架构组织：采集层（数据源）→ 结构化层（知识库）→ 检索层（导航/标签）→ 产出层（提交物）。

## 目录结构

| 目录 | 用途 | 快速定位 |
|------|------|---------|
| `01-competition-rules/` | 赛题规则、评审标准与提交要求 | 参赛准备、规则核对 |
| `02-literature-data-sources/` | 文献数据资源：Sciverse API、Sci-Base、MinerU | 数据接入、证据检索 |
| `03-materials-databases/` | 材料数据库：MP、OQMD、NOMAD、AFLOW、JARVIS | 数据交叉验证、路线A |
| `04-basic-task-literature-agent/` | 基础任务：文献调研 Agent 设计与实现 | 必做任务 |
| `05-advanced-route-a-SPR/` | 路线A：构效关系发现 | 进阶路线 |
| `06-advanced-route-b-simulation/` | 路线B：模拟方法创新 | 进阶路线 |
| `07-advanced-route-c-synthesis/` | 路线C：合成路线与工艺设计 | 进阶路线 |
| `08-frontier-research/` | 材料智能体前沿论文、综述与评测基准 | 方法参考、对标 |
| `09-toolchain/` | Python 工具库、模拟软件、LLM 工具集成 | 工程实现 |
| `10-submission-templates/` | 提交材料模板与代码仓库清单 | 初赛/复赛/决赛产出 |
