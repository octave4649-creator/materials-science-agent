# 材料文献驱动的科学发现智能体 · 初赛方案说明

> 赛道三 · 方向三（材料科学文献驱动的科学发现智能体）｜基本任务 + 路线 A（构效关系发现）
> 版本 v1.0｜2026-08-05

## 1. 问题真实性

**细分领域**：热电材料（thermoelectric materials）。

**真实未解问题**：热电优值 zT = S²σT/κ 的进一步提升受制于电热输运的强耦合（S、σ 与 κ 之间相互制约），组分-结构-性能的定量关联长期依赖试错实验。以本方案聚焦的 GeTe/PbTe/SnTe 基岩盐族热电体系为例，存在三类具体瓶颈：

1. **掺杂协同机制不明**：Na/Sr/Mg 共掺杂 PbTe、Ti/Bi 共掺杂 GeTe 等已展示 zT 提升潜力，但组分-温度联合空间的系统探索缺失（证据见报告 Gap #1-2）。
2. **矛盾结论未消解**：填充方钴矿 CoSb3 的 Yb/Ba 最佳填充量、LAST 体系 zT 峰位（1.5-2.2）在不同文献中报道差异大，缺少统一的组分-性能映射。
3. **高维组分空间无高效导航**：高熵热电（GeTe-PbTe-SnTe 固溶体）组分维度高，尚无搜索算法驱动的设计闭环。

**重要性**：热电材料是余热回收与固态制冷的材料基础，zT 每提升 0.2 即对应显著系统效率提升；上述瓶颈直接制约组分设计的理性化。

## 2. AI 介入点

AI 在本方案中的关键作用**不是替代物理规律，而是加速"从文献到假设再到验证"的发现闭环**：

- **文献挖掘（基本任务）**：用多 Agent 流水线替代人工文献调研，从 2500 万+ OA 文献中检索、抽取成分-结构-性能结构化知识，并自动识别 Research Gap（未探索方向 / 矛盾结论 / 缺失知识连接 / 方法空白）。
- **搜索 × LLM 深度融合（路线 A）**：LLM 不是只写搜索代码，而是以三个角色进入搜索循环——**假设种子生成器**（生成候选掺杂假设作 GA 初始种群）、**科学合理性评估器**（对中间候选打分：热力学可行/物理合理/文献支持）、**搜索空间引导器**（根据中间反馈剪枝聚焦）。GA/MCTS/BO/SR 四种搜索算法在 LLM 引导下在组分空间探索。
- **为何优于传统**：传统试错实验单轮周期长；纯规则搜索无科学语义；纯 LLM 生成缺乏演化优化。三者融合可在可解释约束下高效覆盖高维组分空间。

## 4. 发现信号

「发现」的判定分三级，全部可量化、可回溯：

1. **Gap 新颖性**：识别出的 Gap 按「已知 / 部分已知 / 新知」三级标注，每条附带证据链（DOI + 页码 + 检索记录）。已验证：29 条 Gap 中**新知 15 条 / 部分已知 14 条**。
2. **构效关系可验证性**：搜索产出的掺杂候选在 OQMD/MP 交叉验证，判定为**已知（母体在库且稳定）/ 反例（在库不稳定）/ 新知（库外假设）**。已执行：34 个发现、**182 个候选**，判定分布**已知 124 / 反例 10 / 新知 10 / 验证失败 38**，失败项如实标注（分数掺杂成分直查超时）。
3. **方法增益量化**：三臂消融（GA×LLM vs 纯规则 GA vs 纯 LLM）对比 best_score 与调用成本，量化 LLM 融合增益与 GA 演化增益。

**最小验证标准**：一条构效关系 = 文献证据链 + 数据库验证判定 + 显式可解释关系（符号回归输出解析公式）。

## 技术路线概述

**一句话科学问题**：能否用「文献驱动 + 搜索算法 × LLM 融合」自动发现热电材料中可解释、可验证的掺杂构效关系？

**技术架构**（模块化四 Agent + 路线 A 扩展）：

```
检索 Agent ──► 抽取 Agent ──► 分析 Agent ──► 报告 Agent（基本任务 50%）
                                  │
                                  ▼
           路线 A：GA / MCTS / BO / SR × LLM 三角色融合搜索（进阶 50%）
                                  │
                                  ▼
                   OQMD / Materials Project 数据库交叉验证
```

**方法与创新**：
1. 四 Agent 流水线全链路证据链强制（00-project-rules 4.1），每结论可回溯。
2. LLM 以生成器/评估器/引导器三角色进入搜索循环（非仅写代码），失败自动降级纯规则（可回退）。
3. 符号回归（SR）优先策略——显式解析公式直接支撑「科学意义」评分维度。

**预期成果与风险**：
- 预期：20+ 条可验证构效关系候选、3-4 条高置信新知假设、解析式构效关系 1-2 条。
- 风险：文献语料覆盖不足（已用策展 + LLM 扩展缓解）；分数掺杂成分数据库直查失败率高（已如实标注"验证失败"而非编造）；LLM 幻觉（以 schema 校验 + 证据链 + 确定性组装三件套约束）。
