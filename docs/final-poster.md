# 材料文献驱动的科学发现智能体 · 决赛海报

> GOAI 赛道三 · 方向三（材料科学文献驱动的科学发现智能体）｜基本任务 + 路线 A（构效关系发现）
> 主攻细分领域：**热电材料（掺杂-性能构效关系）**｜2026-09

---

## 1. 问题背景与意义

- **科学问题**：热电优值 zT = S²σT/κ 的电热输运强耦合，使掺杂 × 浓度的组分-性能定量关联长期依赖试错实验；GeTe/PbTe/SnTe 等基岩盐族热电体系存在三类具体瓶颈——掺杂协同机制不明、矛盾结论未消解、高维组分空间无高效导航。
- **AI 介入点**：用「文献证据驱动 + 搜索算法 × LLM 深度融合」自动构建发现闭环，替代「人工文献调研 + 试错实验」的传统范式。
- **意义**：热电材料是余热回收与固态制冷的材料基础；每个可解释、可验证的构效关系都是可复用的理性设计知识。

## 2. 技术架构与创新点

```
┌─────────────── 文献调研四 Agent（基本任务）───────────────┐
│ 检索 Agent → 抽取 Agent → Gap 识别 Agent → 报告 Agent      │
│ (Sciverse 双通道) (LLM+schema) (覆盖率/矛盾/LLM+回查)      │
└──────────────────────┬────────────────────────────────────┘
                       ▼ 29 条 Gap（证据链强制）
┌─────────────── 路线 A：搜索算法 × LLM 融合 ───────────────┐
│ GA / MCTS / BO / SR  ×  LLM 三角色：                      │
│   假设种子生成器 → 科学合理性评估器 → 搜索空间引导器       │
└──────────────────────┬────────────────────────────────────┘
                       ▼ 候选（显式公式 + 评分）
┌─────────────── 数据库交叉验证 + 负反馈闭环 ────────────────┐
│ OQMD 主 + MP 增强 → 新知/已知/反例判定 → 反例回喂剪枝器    │
└──────────────────────────────────────────────────────────┘
```

**创新点（3 条）**：
1. **四 Agent 文献闭环 + 证据链强制**：每个结论（Gap/Finding/验证）强制携带可回溯 EvidenceChain（doc_id/DOI/页码），统一 JSONL 审计日志支撑五项审计。
2. **搜索算法 × LLM 三角色深度融合**：LLM 进入搜索循环本身（生成种子 / 评估合理性 / 引导剪枝），SR 输出显式解析式构效关系，非黑箱。
3. **数据库交叉验证 + 搜索-验证闭环**：A/B 位拆分纯母体解析（Ge0.93Ti0.01Bi0.06Te→GeTe）解决分数掺杂直查失败 38→0；反例母体自动回喂剪枝器。

| 评测项 | 数值 | 证据链 |

**代表性发现**：
- **已知（文献+数据库双支撑）**：GeTe/PbTe 母体稳定（OQMD hull≈0.002 eV/atom）、Na 掺杂 PbTe 提升 zT、Bi2Te3 系掺杂方案——验证搜索空间建模正确。
- **新知候选**：Ge0.94Bi0.06Te（full 臂 0.933）、Mg3Sb2-Zn 3%（llm 臂，5 唯一 dopant 多样性）、ZrNiSn-Ti5% 功率因子 trade-off 量化缺口——标注「与已有结论的关系」并在真值表中验证。
- **可解释性**：LLM 评估器返回科学/可行性/文献支持三维评分 + 机制简述；SR 输出显式公式 + R²，非黑箱。

## 4. 科学意义与展望

- **科学意义**：从 46 篇真实文献出发，全链路自动产出「证据可回溯 + 数据库可验证 + 显式可解释」的构效关系候选——将热电掺杂设计从「试错」推向「文献证据驱动的理性搜索」。
- **如实披露**：LLM 融合增益为负（-8.93%）已定位为真值表覆盖偏置（非 LLM 无能），负结果如实记录；复赛夜间批量扩大 oracle 真值后可重估。
- **展望**：finding/验证结论的 evidence 覆盖补强（Gap 已 29/29 全绿）；LLM 模式下多算法共识清单（规则模式 0 共识，LLM 种子趋同预期可产生共识）作为现场演示加分项；抽取提示词按字段对齐（composition/structure recall 提升）。
